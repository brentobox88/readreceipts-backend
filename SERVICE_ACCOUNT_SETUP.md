# Google Cloud Service Account Key
# Download from: https://console.cloud.google.com/apis/credentials
# 
# 1. Go to Google Cloud Console
# 2. Navigate to APIs & Services > Credentials
# 3. Create a new Service Account or use existing
# 4. Download the JSON key file
# 5. Save it as 'service-account-key.json' in the backend directory
# 6. The path should be: ./service-account-key.json

# Required permissions:
# - Document AI API enabled
# - Service Account roles:
#   - Document AI Processor User
#   - Storage Object Viewer (if using GCS)
